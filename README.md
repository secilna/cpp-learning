# C++ Learning

A collection of C++ exercises covering language fundamentals, classes,
and data structures.

| Topic | Example files |
| --- | --- |
| Variables, data types, and input | `variables.cpp`, `datatypes.cpp`, `cin.cpp` |
| Classes and encapsulation | `classBankAccount.cpp`, `classCounter.cpp`, `privatepublic.cpp` |
| Data structures | `sortedListADT.cpp` |

## Run an example

Compile and run `hello.cpp` from the repository folder:

```sh
clang++ -std=c++11 hello.cpp -o hello
./hello
